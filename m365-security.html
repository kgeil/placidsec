Microsoft 365 Security

Executive Summary

Ten Priorities for Microsoft 365 and Entra ID

Most Microsoft 365 break-ins start the same way: a stolen password, a malicious app approval, or a hijacked mailbox used to redirect payments. These ten controls close those doors.

I drew them from the Center for Internet Security (CIS) benchmarks for Microsoft 365, Azure and Entra ID, and ranked them by how much real-world compromise each one prevents. The first few deliver the most protection.

  1. Require MFA for every user

    A password alone is not enough. Every sign-in also needs a second check, such as an approval in the Microsoft Authenticator app.

  2. Block legacy authentication

    Turn off older sign-in methods that cannot ask for that second check and give attackers a way around it.

  3. Lock down privileged accounts

    Keep administrators few, give them separate admin accounts, set up two emergency accounts, and grant admin rights only when needed.

  4. Phishing-resistant MFA for admins; retire weak methods

    Give administrators security keys or passkeys that phishing sites cannot capture, and retire text-message and phone-call codes.

  5. Control app registration and consent granting

    Only IT can approve apps that read company mail and files. Staff request apps instead of approving them on their own.

  6. Block automatic external mail forwarding

    Stop an intruder from quietly copying a mailbox's mail to an outside address.

  7. Turn on audit logging and keep a copy

    Record who did what, and keep a copy outside Microsoft 365 where an attacker cannot erase it.

  8. Email authentication and Defender for Office 365

    Stop others sending email that pretends to be from your domain, and check links and attachments before staff open them.

  9. Block device code flow; add risk-based access

    Close a sign-in trick used in current phishing campaigns, and challenge or block sign-ins that look suspicious.

  10. Modern password and lockout policy

    Ban easy-to-guess passwords, end forced password changes that lead to weaker ones, and slow down password guessing.

Where to Start

Items 1 to 3 Come First

Together, the first three stop the large majority of account takeovers, and they can usually be done in days rather than weeks.

Most of this list works with Microsoft 365 Business Premium or E3. A few parts of items 3, 8 and 9 need E5 or an add-on license, and each can be phased in later.
